# Portal para Desarrolladores de NTARI

El Portal para Desarrolladores de NTARI es el repositorio oficial de documentación mantenido por el Network Theory Applied Research Institute (NTARI).

Este repositorio se convertirá en la fuente autorizada de la documentación de NTARI orientada a desarrolladores, incluidas futuras guías de ingeniería, referencias de arquitectura, notas operativas, documentación de proyectos y recursos para contribuidores. Actualmente, el portal se mantiene como un repositorio de GitHub centrado en Markdown y más adelante podría publicarse con una plataforma de documentación dedicada, como Docusaurus.

## Alcance actual

Este repositorio define actualmente la base de gobernanza y contribución del Portal para Desarrolladores. Todavía no se han creado páginas de documentación.

## Mantenedor

La documentación de este repositorio es mantenida por NTARI.
