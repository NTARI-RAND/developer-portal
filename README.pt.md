# Portal do Desenvolvedor da NTARI

O Portal do Desenvolvedor da NTARI é o repositório oficial de documentação mantido pelo Network Theory Applied Research Institute (NTARI).

Este repositório se tornará a fonte de referência da documentação da NTARI voltada a desenvolvedores, incluindo futuras orientações de engenharia, referências de arquitetura, notas operacionais, documentação de projetos e recursos para contribuidores. Atualmente, o portal é mantido como um repositório no GitHub com prioridade para Markdown e poderá, mais adiante, ser publicado com uma plataforma de documentação dedicada, como o Docusaurus.

## Escopo atual

Atualmente, este repositório define a base de governança e de contribuição do Portal do Desenvolvedor. As páginas de documentação ainda não foram criadas.

## Mantenedor

A documentação deste repositório é mantida pela NTARI.
