# Portail des développeurs NTARI

Le Portail des développeurs NTARI est le dépôt de documentation officiel maintenu par le Network Theory Applied Research Institute (NTARI).

Ce dépôt deviendra la source de référence pour la documentation de NTARI destinée aux développeurs, notamment les futurs conseils d'ingénierie, les références d'architecture, les notes opérationnelles, la documentation des projets et les ressources pour les contributeurs. Le portail est actuellement maintenu sous la forme d'un dépôt GitHub centré sur le Markdown et pourra ultérieurement être publié au moyen d'une plateforme de documentation dédiée telle que Docusaurus.

## Périmètre actuel

Ce dépôt définit actuellement les fondements de la gouvernance et des contributions pour le Portail des développeurs. Les pages de documentation n'ont pas encore été créées.

## Mainteneur

La documentation de ce dépôt est maintenue par NTARI.

## Contribuer

Les contributions à la documentation sont les bienvenues par le biais des issues et des pull requests GitHub. Veuillez lire [`CONTRIBUTING.md`](CONTRIBUTING.md) avant de proposer des modifications.

## Code de conduite

La participation à ce dépôt est régie par le code de conduite Contributor Covenant. Voir [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).

## Sécurité et problèmes liés au dépôt

Pour signaler des problèmes d'intégrité de la documentation, des préoccupations concernant la configuration du dépôt ou d'éventuels problèmes de sécurité, voir [`SECURITY.md`](SECURITY.md).
