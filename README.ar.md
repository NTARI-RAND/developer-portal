# بوابة المطوّرين لدى NTARI

بوابة المطوّرين لدى NTARI هي مستودع التوثيق الرسمي الذي يتولّى صيانته معهد البحوث التطبيقية في نظرية الشبكات (Network Theory Applied Research Institute, NTARI).

سيصبح هذا المستودع المصدرَ المرجعي المعتمد لتوثيق NTARI الموجّه إلى المطوّرين، بما في ذلك الإرشادات الهندسية المستقبلية، والمراجع المعمارية، والملاحظات التشغيلية، وتوثيق المشاريع، وموارد المساهمين. وتُدار البوابة حاليًا بوصفها مستودع GitHub يعتمد Markdown أولًا، وقد تُنشر لاحقًا عبر منصة توثيق مخصّصة مثل Docusaurus.

## النطاق الحالي

يحدّد هذا المستودع حاليًا أسس الحوكمة والمساهمة الخاصة ببوابة المطوّرين. ولم تُنشأ صفحات التوثيق بعد.

## مشرف الصيانة

يتولّى NTARI صيانة التوثيق في هذا المستودع.

## المساهمة

نرحّب بالمساهمات في التوثيق عبر issues وpull requests على GitHub. يُرجى قراءة [`CONTRIBUTING.md`](CONTRIBUTING.md) قبل اقتراح أي تغييرات.
