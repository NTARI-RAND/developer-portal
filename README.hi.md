# NTARI डेवलपर पोर्टल

NTARI डेवलपर पोर्टल, Network Theory Applied Research Institute (NTARI) द्वारा अनुरक्षित आधिकारिक दस्तावेज़ीकरण रिपॉज़िटरी है।

यह रिपॉज़िटरी NTARI के डेवलपर-सम्मुख दस्तावेज़ीकरण का प्रामाणिक स्रोत बनेगी, जिसमें भविष्य का इंजीनियरिंग मार्गदर्शन, आर्किटेक्चर संदर्भ, परिचालन नोट्स, परियोजना दस्तावेज़ीकरण और योगदानकर्ता संसाधन शामिल हैं। पोर्टल वर्तमान में Markdown-प्रथम GitHub रिपॉज़िटरी के रूप में अनुरक्षित है और बाद में Docusaurus जैसे किसी समर्पित दस्तावेज़ीकरण प्लेटफ़ॉर्म के साथ प्रकाशित किया जा सकता है।

## वर्तमान दायरा

यह रिपॉज़िटरी वर्तमान में डेवलपर पोर्टल के लिए अभिशासन और योगदान की नींव परिभाषित करती है। दस्तावेज़ीकरण पृष्ठ अभी तक नहीं बनाए गए हैं।
