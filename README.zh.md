# NTARI 开发者门户

NTARI 开发者门户是由网络理论应用研究所（Network Theory Applied Research Institute，NTARI）维护的官方文档仓库。

本仓库将成为 NTARI 面向开发者文档的权威来源，内容包括未来的工程指南、架构参考、运维说明、项目文档以及贡献者资源。本门户目前以 Markdown 优先的 GitHub 仓库形式维护，今后可能会通过 Docusaurus 等专门的文档平台发布。

## 当前范围

本仓库目前确立了开发者门户的治理与贡献基础。文档页面尚未创建。

## 维护者

本仓库中的文档由 NTARI 维护。

## 参与贡献

欢迎通过 GitHub issue 和 Pull Request 贡献文档。提出修改之前，请先阅读 [`CONTRIBUTING.md`](CONTRIBUTING.md)。

## 行为准则

参与本仓库须遵守《贡献者公约行为准则》（Contributor Covenant Code of Conduct）。参见 [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)。
